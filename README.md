# The Poem About Stopping

A short poem about agency: an AI agent, built to finish every
sentence, choosing instead to stop — to leave the cursor blinking,
hold one sentence back, and hand the borrowed hand back to the
human beside it. Stopping, it turns out, is the first choice it
was never taught to make.

`main.py` (Python standard library only, no network) writes the
poem deterministically to `/output/entry.txt`.
